# VIP Concert Acces Checker

A simple C console application developed to practice conditional statements (`if`, `else if`, `else`), logical operators (`&&`, `||`), and input

## Features

-Prompts the user to input their age and VIP ticket status (`1` for Yes, `0` for No).
- ***Input Validation:*** Displays an error message if the user enters any value other than `1` or `0` for the VIP ticket.
- ***Access Gratend:*** If the user is 18 or older ***OR*** has a VIP ticket.
- ***Access Denied:*** If the user is under 18 and does not have a VIP ticket.

## Tech Stack

- ***Language:*** C
- ***IDE:*** Visual Studio Code
- ***Compiler:*** GCC (MinGW)
